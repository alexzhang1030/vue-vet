# Vue Vet roadmap

Product goal, audience, and non-goals: [goal](.agents/docs/goal.md). System
shape and crate boundaries: [architecture](.agents/docs/architecture.md).

## Where we are

- Milestones M0–M4 (vertical slice, local doctor, project intelligence, CI and
  distribution, editor and agent surface) are complete on `main`; the tracker
  [#14](https://github.com/alexzhang1030/vue-vet/issues/14) stays open for
  Beta coordination only, and [#224](https://github.com/alexzhang1030/vue-vet/issues/224)
  records the source-contract rule series.
- Current rule catalog: `vue-vet --list-rules` or
  [docs/rules/README.md](docs/rules/README.md) (generated by
  `just rules-catalog`).
- Channels: crates.io (`vue_vet_core`, `vue_vet_reactivity`, `vue_vet_plugins`),
  npm (`vue-vet` launcher + `@vue-vet/*` platform packages), and GitHub Release
  archives, all on one version train ([install](docs/install.md)).
- Surfaces: CLI (text / JSON v1 / SARIF / GitHub annotations, `--fix-safe`,
  `--explain`, `--explain-scope`), `--lsp`, `--mcp`.

## Beta (do this next)

Cut a Beta tag when the
[Beta cut checklist](docs/quality-baselines.md#beta-cut-checklist) is green:

1. Gates: `just roll-rust`, `just compat-matrix`, `just quality-gates`,
   `just oracle`, CodSpeed, Codecov, cross-platform CI, native release matrix
   ([quality gates](docs/quality-gates.md)).
2. Notes: link [quality baselines](docs/quality-baselines.md), the CodSpeed
   report for the release commit, and any precision expectation delta.
3. Corpus: the checksummed projects in `fixtures/quality` keep their TP labels
   and project-level `false_positive` pins.

## After Beta (does not block the tag)

- Real-repo offline false-positive passes (see the spot-check section of
  [quality baselines](docs/quality-baselines.md)).
- Oracle-backed long-tail Factory / `.d.ts` / auto-import seeds — never name
  allowlists without evidence.
- Additional single-file safe-fix producers; multi-file fix transactions and
  platform-metadata policy ([edit model](docs/edit-model.md), issue #9).
- A single high-signal Intent Prefer rule only when write/escape evidence is
  solid ([#132](https://github.com/alexzhang1030/vue-vet/issues/132) is
  deferred).
- A documented stable API for third-party integrations beyond JSON v1.

## 1.0

- Stable configuration and diagnostic contracts.
- Vue and Nuxt reference suites maintained in CI.
- Documented upgrade policy for Vize and Oxc
  ([vize compatibility](docs/vize-compatibility.md)).
- Security, contribution, release, and support policies in place.

## Non-goals before Beta

Replacing `vue-tsc`, becoming a formatter or bundler, speculative AI fixes by
default, or matching rule counts at the expense of precision.
